# 15 分钟生活圈 · 使用说明

「15 分钟生活圈」帮助你从任意一个中心点出发，理解步行可达范围、周边民生设施分布以及可能存在的服务缺口。本文档面向使用者，介绍如何上手、各功能入口和使用时需要注意的事项。

---

## 一、这个工具能做什么

- **查看步行生活圈**：从中心点出发，基于真实步行路网展示 15 分钟内可以到达的范围，而不是简单画一个圆。
- **核对民生设施**：按类别查看菜市场、药店、小学等设施的位置，以及它们是否在可达范围内。
- **生成体检报告**：把分析条件、结果、未知部分、数据来源和限制整理成一份可复核的报告。

**需要记住的边界**：单个中心点的结果不能代表整个社区；设施数量不代表容量、质量或营业状态；工具不会自动生成综合评分。

---

## 二、使用前准备

| 项目 | 建议 |
| --- | --- |
| 设备 | 桌面电脑或笔记本（分析过程需要一定算力） |
| 浏览器 | Chrome、Edge 或 Firefox 的近两年稳定版本 |
| 网络 | 在线 Demo 需要联网；本地运行可离线使用模拟数据 |
| 屏幕 | 建议 1280×720 以上分辨率，便于查看地图与报告 |

## 三、开始使用

### 方式一：在线 Demo（推荐新用户）

1. 打开首页，点击「打开 Demo」进入演示环境。
2. Demo 使用固定模拟数据，用于快速体验完整流程，**不代表真实社区结论**。

### 方式二：本地运行完整分析

如果你需要在本地使用真实数据进行分析，需要分别启动后端和前端。

**1. 申请百度地图 API**

访问百度地图开放平台：https://lbsyun.baidu.com/

1. 使用百度账号登录，完成开发者认证（个人或企业）。
2. 进入「控制台」→「应用管理」→「我的应用」，点击「创建应用」。
3. 填写应用信息：
   - **应用名称：** 自定义，如「15分钟生活圈」。
   - **应用类型：** 选择「浏览器端」。
   - **启用服务：** 勾选「浏览器端AK」及所需的 Web 服务 API。
   - **安全配置（白名单）：** 填写允许访问的域名或 IP，开发阶段可填 `*` 表示不限制。
4. 创建完成后，在「我的应用」列表中可以查看并复制 AK。

> AK 相当于账号凭证，请勿提交到公开仓库或分享给他人。如怀疑泄露，请在控制台重置。

**2. 配置环境变量**

把 AK 写入本地环境变量，供后端读取：

```bash
# Windows CMD
set BAIDU_MAP_AK=你的百度AK

# Windows PowerShell
$env:BAIDU_MAP_AK="你的百度AK"

# macOS / Linux (bash/zsh)
export BAIDU_MAP_AK="你的百度AK"
```

以上命令仅在当前终端会话有效。如需永久配置，请按以下方式操作：

- **Windows：** 右键「此电脑」→ 属性 → 高级系统设置 → 环境变量 → 新建系统变量，变量名 `BAIDU_MAP_AK`，变量值填入你的 AK。
- **macOS：** 编辑 `~/.zshrc`（或 `~/.bash_profile`），添加 `export BAIDU_MAP_AK="你的百度AK"`，然后执行 `source ~/.zshrc`。
- **Linux：** 编辑 `~/.bashrc`（或 `~/.profile`），添加 `export BAIDU_MAP_AK="你的百度AK"`，然后执行 `source ~/.bashrc`。

修改后需要重新打开终端或重启编辑器才会生效。

**3. 准备 OSM 路网数据**

使用 OSM 方案前，需要先在本地下载目标区域的路网数据。推荐使用 OSMnx 自动下载：

```python
import osmnx as ox

# 按城市名称下载
graph = ox.graph_from_place("上海市青浦区", network_type="walk")
ox.save_graphml(graph, "data/roads.graphml")

# 或按经纬度范围下载
graph = ox.graph_from_bbox(31.25, 31.20, 121.50, 121.45, network_type="walk")
ox.save_graphml(graph, "data/roads.graphml")
```

也可以从 OpenStreetMap 官网或 Geofabrik 下载 `.osm` 或 `.pbf` 文件，放入 `data/` 目录。

> 路网数据文件较大，建议只下载分析所需的区域，避免占用过多磁盘空间。

**4. 启动后端与前端**

```bash
# 后端
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000

# 前端
npm install
npm run dev
```

**5. 在浏览器中打开**

访问终端提示的地址（通常为 `http://localhost:5173`），即可进入分析工作台。

## 四、操作流程

### 第 1 步：选择分析位置

使用预设样例、在地图上选点，或手动输入经纬度。请确认本次分析从哪个中心点开始。

> 手动输入坐标时使用 WGS84 坐标系，注意顺序为纬度在前、经度在后。

### 第 2 步：查看步行生活圈

在地图上查看 15 分钟可达范围、已知可达区域、未知区域和计算质量。沿步行路网行进，绕行与硬约束都会被保留。

### 第 3 步：核对民生设施

按类别筛选菜市场、药店、小学等设施，查看名称、位置、是否在圈内以及来源证据。

### 第 4 步：生成体检报告

汇总条件、结果、服务缺口、未知部分、数据来源和限制说明，方便复核与分享。

## 五、如何理解结果

**15 分钟圈与 1 公里判断是两套独立指标**

- 15 分钟圈：基于步行路网，回答「能走到哪里」。
- 1 公里判断：基于直线距离，回答「周边是否存在某类设施」。

两者不会相互替代，请勿混用。

**「未知区域」是什么意思**

当某方向数据不足、计算预算停止或服务异常时，地图会保留为「未知」，而不会静默标记为不可达。详情可在报告的结果说明中查看。

**结果的可信度边界**

- Demo 是可操作的模拟数据演示，用于验证流程一致性，不代表真实结论。
- 数据不足、部分结果、预算停止和服务异常都会保留状态。
- 单点分析不等于全社区评价。

## 六、常见问题

**Q：为什么有些按钮点了没反应？**
A：对应的外部入口尚未配置，页面会显示「待配置」。请联系项目维护者或参考部署说明完成配置。

**Q：为什么地图上有些地方是空的？**
A：这些是未知区域，表示该方向缺少足够数据，并不代表不可达。

**Q：可以用手机操作吗？**
A：介绍页可以手机浏览，但完整分析建议在桌面浏览器中进行，以获得更好的地图交互体验。
