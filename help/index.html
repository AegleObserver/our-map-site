01使用说明

这个工具能做什么

  • 查看步行生活圈：从中心点出发，基于真实步行路网展示 15 分钟可达范围。
  • 核对民生设施：按类别查看菜市场、药店、小学等设施位置及是否在范围内。
  • 生成体检报告：汇总条件、结果、未知部分、来源与限制，便于复核。

单个中心点的结果不能代表整个社区；设施数量不代表容量、质量或营业状态。

开始使用

  1. 选择分析位置：使用预设样例、地图选点，或手动输入经纬度（WGS84，纬度在前）。
  2. 查看步行生活圈：查看 15 分钟范围、已知可达区域、未知区域与计算质量。
  3. 核对民生设施：筛选类别，查看名称、位置、圈内状态及来源证据。
  4. 生成体检报告：导出包含条件、结果、缺口与限制的完整报告。

如何理解结果

  • 两套独立指标：15 分钟圈基于步行路网回答「能走到哪里」；1 公里判断基于直线距离回答「周边是否存在某类设施」。
  • 未知区域：数据不足、预算停止或服务异常时会保留为「未知」，不会被静默标记为不可达。
  • 可信度边界：Demo 为模拟数据，单点分析不等于全社区评价。

02环境依赖

基础软件

  • Node.js：20 或更高版本（发布站与前端）。
  • Python：3.10 或更高版本（分析后端）。
  • 浏览器：Chrome / Edge / Firefox 近两年稳定版。

申请百度地图 AK

访问百度地图开放平台：https://lbsyun.baidu.com/

  1. 使用百度账号登录，完成开发者认证（个人或企业）。
  2. 进入「控制台」→「应用管理」→「我的应用」，点击「创建应用」。
  3. 填写应用信息：
    • 应用名称：自定义，如「15分钟生活圈」。
    • 应用类型：选择「浏览器端」。
    • 启用服务：勾选「浏览器端AK」及所需的 Web 服务 API。
    • 安全配置（白名单）：填写允许访问的域名或 IP，开发阶段可填 * 表示不限制。
  4. 创建完成后，在「我的应用」列表中可以查看并复制 AK。

AK 相当于账号凭证，请勿提交到公开仓库或分享给他人。如怀疑泄露，请在控制台重置。

环境变量

百度地图 API Key 通过环境变量注入，不要写入源码：

# Windows CMD
set BAIDU_MAP_AK=你的百度AK

# Windows PowerShell
$env:BAIDU_MAP_AK="你的百度AK"

# macOS / Linux (bash/zsh)
export BAIDU_MAP_AK="你的百度AK"

永久配置

Windows：右键「此电脑」→ 属性 → 高级系统设置 → 环境变量 → 新建系统变量，变量名 BAIDU_MAP_AK，变量值填入你的 AK。

macOS：编辑 ~/.zshrc（或 ~/.bash_profile），添加 export BAIDU_MAP_AK="你的百度AK"，然后执行 source ~/.zshrc。

Linux：编辑 ~/.bashrc（或 ~/.profile），添加 export BAIDU_MAP_AK="你的百度AK"，然后执行 source ~/.bashrc。

  • 中心点：一个经纬度坐标（WGS84）。
  • 设施：菜市场、药店、小学，含坐标、是否在圈内与来源标记。

04常见问题

为什么有些按钮点了没反应？

对应的外部入口尚未配置，页面会显示「待配置」。请联系项目维护者或参考部署说明完成配置。

为什么地图上有些地方是空的？

这些是未知区域，表示该方向缺少足够数据，并不代表不可达。

可以用手机操作吗？

介绍页可以手机浏览，但完整分析建议在桌面浏览器中进行，以获得更好的地图交互体验。

15 分钟圈与 1 公里判断有什么区别？

前者基于步行路网回答「能走到哪里」，后者基于直线距离回答「周边是否存在某类设施」，两者独立计算，不可相互替代。
