HELP / 帮助文档

本机运行指南

从准备环境到在浏览器中打开分析工作台，按以下步骤依次操作即可。

01准备工作

设备与系统要求

  • 操作系统：Windows 10/11、macOS 12+ 或主流 Linux 发行版（64 位）。
  • 内存：建议 8 GB 及以上，路网分析与报告生成需要一定内存开销。
  • 磁盘空间：至少预留 2 GB，用于安装包、OSM 路网数据与构建产物。
  • 浏览器：Chrome / Edge / Firefox 近两年内的稳定版本。

必需软件

  • Node.js：18 或更高版本（含 npm）。
  • Python：3.10 或更高版本，用于启动后端服务。
  • Git：用于克隆源码仓库（可选，也可直接下载压缩包）。

02具体操作

下载安装包

从 GitHub 源码仓库 克隆或下载最新版本：

git clone https://github.com/PennEwan/Baidu-map.git
cd Baidu-map

申请百度 API 并配置 AK

  1. 登录百度地图开放平台，创建「浏览器端」应用，获取 API Key（AK）。
  2. 将 AK 配置到本地环境变量中，供后端读取：
# Windows (PowerShell)
setx BAIDU_MAP_AK "你的百度AK"

# macOS / Linux
export BAIDU_MAP_AK="你的百度AK"

环境变量配置后需要重新打开终端或重启 IDE 才会生效。

下载 OSM 路网数据

从 OpenStreetMap 获取目标区域的路网数据，放入项目数据目录：

# 示例：通过 overpass-api 下载某区域路网并保存
curl -o data/roads.osm "https://overpass-api.de/api/interpreter?data=[out:json];way[highway]({{bbox}});out;"
# 或直接使用项目文档中提供的预处理数据

03运行网站

启动后端

pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000

启动前端

npm install
npm run dev

在浏览器中打开

启动成功后，在浏览器中访问 http://localhost:5173（或终端提示的本地地址），即可进入分析工作台。

前端开发服务器会代理后端请求，确认后端已在 :8000 端口运行即可。
